# reaction

The `tm.list` file is a list of tautomer specified by a bitmask (as previously described in the antechamber section) and would normally be generated with random values by `polymof_setup.py`, but has been included here so that the script can run independently of other steps.  The `IM.pdb` was generated by Openbabel, `IM.prmtop` by antechamber while `Fe.pdb` and `Fe.prmtop` were generated by hand.
